# 版本与验证范围

## 发布内容

- 地图：使用者确认采用的 V10 最终版。
- 比例：原纽北布局整体 1.5 倍；每圈约 31.25 公里。
- 游戏：韩服 P5136，`village_R01` 正向槽位，界面标题 `빌리지 고가의 질주`。
- 资源：草地重复纹理、恢复两处碗状弯混凝土面及遗漏地面，补充部分公里牌和路面涂鸦。
- 范围补丁：12000 上限，仅作用于本次匹配的游戏进程。发布版代码与已验收 V10 的代码字节相同。
- 分享启动器：独立客户端、干净默认配置、独立的仅回环服务；没有复制原工作区、截图、日志或个人存档。

## 已有证据

1. V10 原启动入口已由使用者测试并确认“这次可以了，就按这版作为最终版吧”。
2. 对应加载记录中，823686/823686 个 Track 三角形、18604/18604 个 Course 三角形导入，结果采集时游戏仍运行。导入计数不是通过检查点或完成圈数的证明。
3. V10 的物理、起点、检查点和复位数据与 V8 一致；V8 对应的 30 组离线路线回放检查通过。
4. 六张同视角离线预览检查了起点、林间路段和 Karussell；这些是离线渲染，不是原生游戏截图。
5. 分享包通过中文/空格路径安装、目录迁移、重复安装、修改过的客户端被拒绝、资源摘要、32 位范围补丁编译、本地服务启动/探测、连接器 dry-run 和服务退出检查。
6. ZIP 全部成员经过 CRC 和 SHA-256 回读验证。

## 仍应区分的范围

原 V10 地图的用户验收，不等于精简分享入口已经在各种电脑上完成原生驾驶验证。分享入口的真实启动、加载、渲染、手动复位和计圈，仍需使用者在自己的电脑上确认。

贴图和渲染是适配跑跑旧引擎的近似表现，不等同于 Assetto Corsa 的多层材质、光照或 CSP 效果。没有扩大车辆参数、增加联网支持或验证所有车型。

安装器会拒绝关键文件身份不匹配的客户端。文件校验用于匹配已验证版本，并非对第三方客户端来源的官方认证。
