# 安装与使用指南

本指南适用于 Windows 10/11 64 位、系统自带 Windows PowerShell 5.1。补丁为 V10 最终版，地图和碰撞规模保持原版纽北布局的 1.5 倍；原版游戏 EXE 不作磁盘修改。

## 2. 首次安装

从零开始下载、保留客户端 ZIP、解压原版并安装独立副本，建议至少预留 **12 GB** 可用空间。已有完整客户端时，补丁安装位置至少再预留 **4.5 GB**。

1. 校验客户端 ZIP 后，完整解压到如 `D:\Games\OriginalP5136`。实际需要输入的根目录通常是 `D:\Games\OriginalP5136\KartRider_5136`，其中直接包含 `KartRider.exe`、`KartRider.pin` 和 `Data`。
2. 校验补丁 ZIP，解压到另一个可写目录，例如 `D:\Games\NordPatch`。**不要放到原客户端目录内部，不要从压缩包内直接运行**，避免使用需要管理员写权限的 Program Files。
3. 打开解压后的 `Nordschleife-P5136-Final-1.5x-v1` 文件夹，双击 `1-Install.cmd`。
4. 输入第 1 步的客户端根目录，按回车。带空格和中文的路径受支持。
5. 等待“安装完成”。安装器会先校验版本，再复制所需文件到补丁自己的 `app/runtime/nord-full-v10/KartRider_5136`，然后安装地图。它不会修改输入的原版客户端，也不会复制 `Profile` 个人目录。

安装只做一次。安装器校验的原版地图与挂载表摘要也列在仓库 `checksums.json` 中；仅 EXE 匹配不足以让修改过地图的客户端通过安装。

## 3. 每次启动游戏

1. 正常退出任何已经打开的跑跑卡丁车。
2. 双击补丁目录的 **`2-Play.cmd`**，同意 Windows UAC。脚本使用 32 位 Windows PowerShell，以与原游戏进程匹配。
3. 等游戏显示大厅或“我的房间”。**先不要点击开始比赛**。
4. 按 Alt+Tab 回启动窗口，按一次回车。窗口提示“准备完成”后，范围补丁才已经启用。
5. 切回游戏，选 **`빌리지 고가의 질주`**、正向。中文含义为城镇高速，选图标题保留原地图名字。首次可用练习车。
6. 正常退出游戏后，启动窗口会结束，本次本地服务自动关闭。不要在游戏仍运行时直接关闭启动窗口。

昵称自动为 `NordPlayer`。服务器只监听 `127.0.0.1`，不需要配置路由器端口转发。范围补丁只作用于本次游戏进程，退出后失效，所以**每次重新启动都要在大厅按回车**。

## 4. 存档、移动和卸载

- 离线角色数据：`app/user/profiles`。
- 启动与服务日志：`app/user/logs`，按时间分目录。
- 整个安装目录可以移动，脚本使用相对路径；不要只移动内部游戏文件。
- 卸载时先退出游戏及启动窗口，按需备份 `app/user/profiles`，再删除整个补丁目录。输入的原版客户端无需恢复。
- 给朋友分享原始 Release ZIP。不要分享你使用后的整个目录，其中会有你的存档和日志。

## 5. 常见问题

| 现象 | 处理 |
| --- | --- |
| 找不到 `payload`、`vendor` 或游戏文件 | 确认下载的是 Release 补丁 ZIP，而不是仓库源码 ZIP；先运行安装入口。 |
| 文件版本或内容不匹配 | 停止安装，确认原版 ZIP、EXE、地图和 `aaa.pk` 摘要；不能使用其他地区客户端或已打过地图补丁的目录。 |
| 安装被中断 | 失败目录会保留。重新把原始补丁 ZIP 解压到新的空目录，再安装，不覆盖半安装目录。 |
| UAC 被拒绝 | 关闭本次启动窗口，重新运行 `2-Play.cmd`，由用户确认管理员提示。 |
| 开局掉落、范围碰撞异常 | 确认先进入大厅，再回脚本按回车，看到“准备完成”后才开比赛。不要直接双击内部 `KartRider.exe`。 |
| 端口被占用 | 先正常退出另一个该补丁的游戏和启动窗口。不要让 agent 杀掉无法确认归属的进程。 |
| 草地或碗状弯仍有异常 | 保存驾驶截图和最新日志目录，注明地图、正反向、车型及出现位置。 |
| 闪退、长时间无窗口 | 保存 `app/user/logs` 最新目录和完整错误提示；不要反复自动启动或关掉版本校验。 |

程序脚本已通过中文路径安装、迁移、重复安装、错误版本拒绝、32 位编译、本地服务与连接计划检查。原 V10 地图已由使用者接受为最终版；精简分享入口尚未单独完成原生驾驶验收。见[验证范围](验证范围.md)。
